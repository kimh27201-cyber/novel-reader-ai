# Android 真机适配验收清单

本阶段不提前打包发布；等 H5 主链路稳定后，再用这份清单做真机适配、权限验证和安装包展示。

当前导入页的扫码、文件选择、剪贴板和文件读取已经统一走 `common/importAdapters.js`。真机阶段优先验证这个适配层在 Android App 端的实际返回值和权限提示。
“我的”页已经提供后端地址保存、真机地址提示和 `/api/health` 自检，真机联调先用它确认手机能访问电脑后端。
当前“我的”页还提供“APK 展示准备”卡片，用于集中确认局域网后端地址、自检、登录和后续 HBuilderX 手动打包项。
“我的”页新增“一键演示准备”，用于预填演示账号、复制后端启动命令，并提示录屏主链路顺序。

## 准备

- 使用 HBuilderX 打开 `D:\Codex\novel-reader-uniapp`。
- 后端使用局域网可访问地址启动，不要在真机里使用 `127.0.0.1`。
- 推荐启动命令：`.\.venv\Scripts\python.exe -m uvicorn app.main:app --reload --host 0.0.0.0 --port 8000`。
- 在电脑上确认局域网 IP，例如 `192.168.x.x`，手机端后端地址填写 `http://192.168.x.x:8000`。
- 在“我的”页确认后端地址和登录状态正常。
- 在“我的”页确认“APK 展示准备”前 3 项显示“已就绪”。
- 点击“一键演示准备”，确认演示账号预填、启动命令复制、主链路清单显示正常。
- 准备一个合法书源 JSON 文件、一个书源二维码和一段可导入剪贴板内容。

## 必测功能

- 扫码导入：点击“扫码导入”，确认相机权限弹窗、扫码成功、取消扫码提示都正常。
- 本地 JSON：点击“本地 JSON”，确认文件选择、非 JSON 拦截、JSON 导入成功。
- 剪贴板：复制书源内容后点击“剪贴板”，确认权限和导入结果。
- 后端地址自检：在“我的”页输入局域网后端地址，点击“保存地址”和“自检后端”，确认健康检查通过。
- APK 展示准备：确认“局域网后端地址 / 后端健康检查 / 后端登录状态”均已就绪，DCloud AppID 和云打包签名作为发行前手动项。
- 一键演示准备：预填 `student / secret123` 后登录，复制后端启动命令，并按导入、搜索、阅读器、AI 记录顺序录屏。
- 真机网络：发现页搜索、书源详情、单源测试、批量检测都能访问后端或目标源。
- 阅读链路：搜索在线书籍、进入详情、解析目录、加入书架、进入阅读器。
- AI 链路：阅读器触发总结/问答，AI 记录页能看到 summary/chat/success/failed。

## 重点风险

- 真机不能访问电脑的 `127.0.0.1`，需要改成电脑局域网 IP 或部署地址。
- Android 文件选择返回结构可能与 H5 不同，需要验证 `tempFiles`、`tempFilePaths`、`path` 是否都能被 `importAdapters` 识别。
- `uni.scanCode` 只在真机/App 端可用，H5 预览会提示不支持。
- 剪贴板权限可能被系统拦截，需要保留清晰失败提示。
- 第三方站点可能限制移动端网络请求，失败源应保留失败原因并被发现页跳过。

## 打包前检查

- `pages.json` 能解析。
- 前端 Node 测试通过，尤其是 `tests/importAdapters.test.mjs` 和 `tests/backendConnection.test.mjs`。
- 后端 pytest 通过。
- README、演示脚本和截图清单已更新到当前功能。
- App 名称、图标、启动页、权限说明不含真实 API Key 或敏感信息。
- `static/branding/` 下的图标和启动页源文件已导出为 HBuilderX 可配置的 PNG 素材。

## 安装包展示建议

- 录屏只展示合法演示源或本地 TXT，不展示未授权内容。
- 先展示登录、导入、批量检测和发现页搜索，再展示阅读器与 AI 记录。
- 如果现场网络不稳定，用 Swagger 和 mock AI 兜底展示核心闭环。
