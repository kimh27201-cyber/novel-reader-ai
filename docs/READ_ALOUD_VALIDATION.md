# 听读功能验收清单

## 自动验证

在项目根目录 `D:\Codex\novel-reader-uniapp` 执行：

```powershell
node tests\readAloud.test.mjs
node tests\readerExperience.test.mjs
node tests\androidTtsBridgeContract.test.mjs
```

测试覆盖正文分段、300 字上限、分页/段落映射、暂停恢复、跳段、过期回调、自动下一章、驱动优先级、偏好持久化和 Android 桥静态契约。

## Chrome H5

1. 用 HBuilderX 运行到浏览器，使用 Chrome 打开阅读页。
2. 从非第一页启动听读，确认从当前页第一段开始。
3. 依次验证暂停、继续、上/下一段、停止和五档语速。
4. 确认当前段高亮，跨页时页码、动画和阅读进度同步更新。
5. 听完一章后确认自动进入下一章；关闭“听读自动进入下一章”后应在章末停止。
6. 切换页面、目录跳转、手动翻页或离开阅读页后，声音必须停止。

## HBuilderX Android App-Plus

1. 在安装了中文系统语音服务的 Android 真机上运行自定义基座。
2. 重复 Chrome H5 的功能项，并确认语音提供方显示为“系统语音”。
3. 将 App 切到后台，确认立即停止；回到前台后需手动重新开始。
4. 在系统中停用中文语音服务后重试，确认页面给出明确错误提示。

## 自建 Android WebView APK

安装已构建的 `V2.apk`，重复 App-Plus 验收项，并额外确认：

1. 本地 TXT、在线书源和后端书架章节都可听读。
2. 下一章加载失败时停止听读，并保留刚才的章节和页码。
3. 连续听读至少三章，无重复、跳段、崩溃或声音残留。
4. 退出阅读器或关闭 App 后，系统 TTS 资源被释放。

## 当前边界

当前版本不包含 iOS、后台/锁屏持续播放、通知栏控制、耳机按键、云端神经网络角色音和定时关闭。正文只交给设备系统 TTS，不上传到本项目的云端语音服务。

## 声音选择页

从阅读设置进入“听读声音”，分别在 Chrome、HBuilderX Android 基座和自建 APK 验证：

1. 页面至少显示“系统默认”；设备存在额外本地中文音色时应一并列出。
2. 每个声音的“试听”和“选择”独立生效，系统默认声音也能试听。
3. 选择声音后返回阅读器，听读、自动翻页和连续下一章持续使用该声音。
4. 重启应用后选择仍保留；卸载已选声音后再次进入页面会恢复系统默认并提示。
5. 试听中返回、切到后台或关闭页面后声音停止。
6. 依次试听“萝莉、大叔、青年、正太、朗诵”，确认五种本地角色效果都能开始和停止，卡片会显示各自音调与节奏。
7. 选择任一角色后返回阅读器，浮动控制条显示角色名称，连续翻页和下一章仍保持该角色效果。
8. 在角色效果与设备声音之间切换，确认选择立即持久化且不会把角色 ID 当成系统音色 ID。
9. 角色效果基于设备系统 TTS 的音调与节奏调整，不应宣称为云端真人或神经网络音色。
