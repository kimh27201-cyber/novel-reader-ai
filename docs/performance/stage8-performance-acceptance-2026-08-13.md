# 第八阶段性能验收报告（2026-08-13）

## 结论

第八阶段已完成底部标签立即切换、5330 源快照/索引复用、运行状态批量写入、后台任务错峰、阅读预加载延后和 AI 声音状态缓存。REA-AN00 暖启动 P95 为 177ms，应用内标签导航 P95 为 4.9ms；GC 后稳态 PSS 约 155–158MB，相对约 269MB 基线降低约 42%。

最终包覆盖安装后的补充复验：冷启动 524ms，进入 5330 源书源页时 PSS 短时升至 391,717KB，3 秒后回落至 150,759KB；书源页正确显示 5330 源和每页轻量列表。

继续优化后，原生 214 个书源分片改为每批最多 16 个读取，避免全部原始 JSON 字符串与解析后对象同时驻留。完整 5330 源首次加载采样峰值降至 212,276KB，约 0.9 秒回落至 151,123KB；相对 391,717KB 基线峰值下降约 45.8%。
