# V2.5 复杂书源兼容增强：开发与验收记录

更新时间：2026-06-18

## 交付范围

V2.5 在原有 CSS / JSON 规则链路上补齐了以下能力：

- 阅读 3.x 多形态请求头解析，统一处理对象、JSON 字符串和逐行 `Key: Value`；H5 代理保留 `User-Agent`、`Referer`、`Cookie` 等必要请求头，日志自动脱敏。
- 发现规则能力识别与 `ruleSearch` 降级，诊断中展示实际使用的规则入口。
- 安全 JS 子集解释器。只开放字符串、JSON、URL、正则、Base64 和 URI 编解码等纯函数，不使用 `eval` / `Function`，拒绝网络、文件、DOM、全局对象和循环执行。
- Android WebView 动态渲染桥接，支持获取渲染后 HTML、读取 Cookie、打开人工登录页并保存登录状态。
- 按书源和域名隔离的 CookieJar，请求自动复用，删除书源时同步清理。
- 六级兼容性诊断：`full_css`、`need_headers`、`need_js_sandbox`、`need_webview`、`need_login`、`unsupported`。

## 关键实现文件

- `common/headerUtils.js`：请求头归一化、代理过滤和脱敏。
- `common/jsRuleSandbox.js`：安全 JS 子集解释器。
- `common/webViewBridge.js`：H5 / Android 渲染桥接统一入口。
- `common/sourceCookieJar.js`：Cookie 隔离、持久化和清理。
- `common/sourceEngine.js`：兼容级别、请求规则解析、WebView 调度。
- `common/bookSources.js`：书源诊断、请求复用、导入预览和全链路调用。
- `android-webview-shell/src/com/novelreader/v1/NovelReaderWebViewParser.java`：Android 渲染、Cookie 和人工登录桥。
- `pages/library/library.vue`：兼容诊断卡、登录操作和 Cookie 管理。

## 兼容边界

| 级别 | 桌面 H5 | Android APK | 处理方式 |
|---|---:|---:|---|
| `full_css` | 支持 | 支持 | 直接执行 |
| `need_headers` | 支持 | 支持 | 经代理或原生请求传递必要请求头 |
| `need_js_sandbox` | 支持 | 支持 | 仅执行安全白名单子集 |
| `need_webview` | 不支持 | 支持 | Android WebView 返回渲染后 HTML |
| `need_login` | 不支持 | 支持 | 用户人工登录并保存 Cookie |
| `unsupported` | 不支持 | 不支持 | 不绕过验证码、强风控、会员和付费限制 |

## H5 与 APK 构建

HBuilderX 云发行要求账号绑定手机号；本项目使用本机内置编译器完成离线生产构建：

```powershell
$env:NODE_ENV='production'
$env:UNI_PLATFORM='h5'
$env:UNI_INPUT_DIR='D:\Codex\novel-reader-uniapp'
$env:UNI_OUTPUT_DIR='D:\Codex\novel-reader-uniapp\unpackage\dist\build\h5'
$env:UNI_MINIMIZE='true'
& 'D:\HBuilderX\plugins\node\node.exe' 'D:\HBuilderX\plugins\uniapp-cli\bin\uniapp-cli.js'

powershell -ExecutionPolicy Bypass -File .\scripts\build_android_webview_apk.ps1
```

APK 输出：`release/android-v2/V2.apk`。构建脚本会执行 v1 / v2 / v3 签名校验。
